## 🚧 What's happening?

TinyPath is currently undergoing a massive evolution. We are migrating our backend from Node.js/Express to **Go (Golang)** to achieve blazing-fast performance, better concurrency, and a more robust architecture.

### What to expect in v2:
- 🐹 **Go-powered Backend:** Lightning fast URL resolution and API responses.
- 🏗️ **Improved Architecture:** Cleaner, more scalable codebase.
- ✨ **New Features:** A brand new era of TinyPath!
